# SARVASETU – Intelligent Public Benefit Delivery Platform

**Discover. Understand. Prepare. Access. Stay Updated.**

## About the Project

SARVASETU is an intelligent public benefit delivery platform designed to help citizens discover government welfare schemes and understand the benefits and eligibility requirements relevant to them.

The platform aims to simplify access to public welfare information through personalized scheme recommendations, document assistance, multilingual accessibility and timely updates.

## Problem Statement

Many citizens face difficulties discovering suitable government schemes, understanding eligibility criteria, identifying required documents and accessing official application resources.

SARVASETU aims to make this information easier to discover and understand through a centralized digital platform.

## Key Features

- **Scheme Discovery:** Explore government schemes across different sectors.
- **AI-Based Recommendations:** Identify potentially relevant schemes based on user profile information.
- **Eligibility Assistance:** Understand scheme eligibility requirements.
- **Document Vault:** Organize documents required for scheme applications.
- **Multilingual Support:** Access platform content in multiple languages.
- **Notifications and Updates:** Stay informed about relevant scheme updates.
- **Citizen Authentication:** Secure user registration and login.
- **Officer Module:** Support authorized scheme information updates.

## Installation and Setup

### Prerequisites

- Node.js and npm
- MongoDB
- Git

### Backend Setup

```bash
cd backend
npm install
```

Configure your environment variables using a local `.env` file based on the required project configuration.

Start the backend using the start script defined in `backend/package.json`.

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Mobile Setup

Open the mobile project directory and follow its Capacitor and Android build configuration.
